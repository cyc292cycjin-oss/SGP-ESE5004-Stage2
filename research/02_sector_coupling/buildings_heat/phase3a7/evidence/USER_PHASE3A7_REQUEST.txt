3. Minimum Defensible Buildings Baseline
--------------------------------------------------

Create a clear fallback hierarchy.

Rule A:
If a country/sector/end-use has sufficiently strong and compatible evidence,
it may be explicitly represented.

Rule B:
If evidence is incomplete,
retain the corresponding energy inside the original direct-electricity or direct-fuel account.

Rule C:
Missing != zero.

Rule D:
Missing != invented heat service.

Rule E:
Never force a common ASEAN space/water split.

Rule F:
Do not require complete device-level detail if it is unlikely to materially affect the ASEAN interconnection question.

reference only.

5. Materiality rule
--------------------------------------------------

Introduce a research-development rule:

A missing parameter/data item should block Full-SC assembly only if there is a credible pathway for it to materially alter:

- major capacity mix,
- cross-border electricity flows,
- country-level investment pattern,
- sector electrification,
- or integrated vs disconnected comparison.

Otherwise document it as a limitation / later refinement and proceed.
