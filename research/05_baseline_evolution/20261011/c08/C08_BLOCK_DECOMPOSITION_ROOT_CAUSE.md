## 1. 结论

C03–C07 的日模型失败可以分成两个**数学上互不相关**的部分：

1. **固定资源块（EXACT）。** 包括 807 个 "fixed resource" Store 和 807 个 "final-energy meter" Link，共 884,472 列、2,203,217 行，约占 LP 的 36%。该块与其余 LP **完全解耦**：触及它的行里没有任何外部列。块内全部列的成本为 0。在求解器坐标下，385 组的可行余量只有约 1e−19 至 4e−16，比 FeasibilityTol 1e−6 小十个数量级以上。全部账户/义务组失败、全部矩阵行失败、全部对偶符号与自由 RC 失败，以及全部 |y|>1e9 的巨大对偶，都只出现在这个块里。
2. **网络主 LP（VERIFIED）。** 共 1,565,533 列、3,839,021 行。历次 stationarity 失败全部在这里，集中于 Line-s 和 Link-p，C03/C06/C07A 依次为 4304/3336/3353 列，块内为 0。这是普通的 Barrier 精度问题，与块无关。

因此，过去的调参和缩放（C05–C07）主要是在一个**零成本、对目标没有任何影响**的可行性子系统上与数值精度对抗。C07 报告改动的 884,472 个 D 和 2,203,217 个 R，与块的列数、行数完全相同。按 C07 代码的定义（新指数减原指数）逐元素核对：实际改变的恰好是 884,472 列和 2,203,217 行，**全部位于块内，块外为 0**；块外原 D/R 均为 2^0（VERIFIED）。

## 2. 块的结构与解耦（EXACT）

逐行核对块内全部 2,203,217 行的系数模式，结果如下：

| 行族 | 行数 | 形式 |
|---|---|---|
| Store-energy_balance（t=0） | 807 | −e₀ − 24·p₀ = −Q_a |
| Store-energy_balance（t>0） | 293,748 | e_{t−1} − e_t − 24·p_t = 0 |
| Store-fix-e-lower / upper | 294,555 ×2 | 0 ≤ e_t ≤ Q_a（上界逐账户精确等于初值 Q_a） |
| ResearchStoreDirection | 294,555 | p_t ≥ 0 |
| 资源 Bus 平衡 | 294,555 | p_t − m_t = 0 |
| 终端 Bus 平衡（385 组 × 365 日） | 140,525 | Σ_{a∈g} m_{a,t} = d_{g,t}（只含本组 meter） |
| meter 容量 | 294,555 ×2 + 807 | 0 ≤ m_t ≤ p_nom，p_nom ≥ 0 |

块内所有系数都精确等于 ±1 或 −24，块内列没有列级界，块内成本全为 0。主 LP 中没有任何行引用块内列。

因此原 LP 可以写成 min c_Mᵀx_M，约束为 x_M ∈ 主可行域，且 x_S ∈ 块可行域。这是一个**可分离问题**：

- 只要块可行，原 LP 的最优值就等于主 LP 的最优值；
- 原 LP 的最优解集 = 主 LP 最优解集 × 块可行集；
- 块内取值对目标和主 LP 都没有任何影响，求解器返回哪一个块内点都是同样"最优"的。

## 3. 块的精确可行性证书（EXACT）

由上述结构可知，每个组的可行条件为 24·Σ_t d_{g,t} ≤ Σ_{a∈g} Q_a。e_t 单调下降且不超过 Q_a，其余约束都可以直接满足。

- 从 LP 的 binary64 RHS 精确读出 385 组的 D 和 Q，全部满足 D ≤ Q。最小余量为 2⁻⁶³ ≈ 1.08e−19，最大约 4.13e−16，均为 LP 坐标下的值。
- 385/385 组的物理值 = 2^k × LP 值，其中 k ∈ [0, 28]。D、Q 和 slack 三者都与 `SCHEME_A_DAILY_EXACT_GROUPS.json` 精确一致。
- 按"逐日、逐账户依次取用"构造了一个有理数解。用原 LP 系数**逐行精确核验全部 2,203,217 行，违约为 0**，块目标贡献为 0。

结论是 BLOCK_FEASIBLE_EXACT。块可行性不再依赖求解器。

## 5. 机制（INFERENCE）

- 块是零成本的纯可行性问题，余量又近乎为零，所以它的对偶集合包含射线：沿射线方向对偶目标不变。内点法的中心路径满足 y·s ≈ μ，松弛 s ≈ 1e−16 时 y 被推到 1e10 至 1e14。这与观察到的 484 个不同巨大取值相符。
- 多账户组内，每天由哪个账户供给是不唯一的，余量越小越敏感。这与 C04 发现的"1/2 账户组全部通过、3/4 账户组全部失败"一致。
- C07B 的 Crossover 需要在 1e−6 容差下，为余量约 1e−16 的退化运输结构找出一个基，最终得到 Status 3。这一解释**合理但尚未证明**，第 7 节的拆分求解可以直接检验它。
- 巨大的块对偶不进入主 LP 的 stationarity，因为两者解耦。所以主 LP 的 Line-s/Link-p 问题是独立的。

## 6. 主 LP 的现状（VERIFIED，非证书）

只用 C07A 返回的主 LP 部分做对偶修复后，真实残差列从 205,339 列降到 5,326 列：Line-s 3376 列、Link-p 1931 列、Link-p_nom 19 列，Σ|r| = 0.365。有限部分的估计差距为 205,250 EUR，相对 4.8e−7。

**这不是严格下界。** 残差列需要有限的列界，而目标截断给出的 Line-s_nom 界在 1.3e7 至 8.4e7 之间（LP 单位），另有 107,463 个非块 Store-p 列需要跨多行传播界。由此得到的严格界远松于 1e−6。因此，现有对偶无法直接给出证书。这一点与 ChatGPT 草案"目标差不得称为证书"的立场一致。
