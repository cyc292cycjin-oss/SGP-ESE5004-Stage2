### R4 求解配置与缩放（第 69 项）

1. **求解器设置**
   - 以 PyPSA-Eur v2025.07.0 `config.default.yaml` 中的 `gurobi-default` 为基础，引用行号。主算设置如下：
     - Method 2（barrier）、Crossover 0；
     - BarConvTol 1e-8（比 PyPSA-Eur 默认值严格，理由：关闭 crossover 后靠内点解精度保证结果）；
     - BarHomogeneous 1（用于区分真正不可行与数值问题）；
     - Threads 8、Seed 固定。
   - 其余参数沿用 PyPSA-Eur。与 PyPSA-Eur 默认值不同的每一项都登记理由。
   - 在配置中加入开关 `research.solver.profile`，取值 `formal_barrier`（主算）和 `crossover_diagnostic`（同样设置，但 Crossover 1）。
2. **缩放（只实施这两项）**
   - (a) 把目标函数常数项移出 LP，包括存量固定运维常数、跨境线 FOM 常数等，求解后再加回；报告中的总成本口径保持不变。
   - (b) 大容量 Store 的能量单位改为 GWh 或 kt，包括生物质池、封存上限、捕集缓冲，与之相连的效率和成本系数同步换算；报告输出时换回 MWh 或 t。
   - 基尔霍夫行的归一化不实施。
3. **等价性检验（在当前 S3 网络上）**
   - 一体化主算 56×3h：缩放前后的目标值（常数项加回后）相对差 ≤ 1e-6。参照值为 S3-7 的 Gurobi barrier 目标 6.98803335e11。
   - 抽查装机、发电、CO₂ 去向等主要量，差异 ≤ 容差。
   - 报告缩放前后的系数范围（矩阵、目标、右端项、边界）和 Gurobi 的警告是否消失。
4. **内点解的配套处理**
   - V5 的 A1/A2 门槛改用内点解评定：原始可行性残差、对偶残差、相对原始–对偶间隙。阈值与 BarConvTol 挂钩，登记依据。
   - 登记统一的清理阈值：报告时绝对值低于阈值的装机、流量、存储记为 0。阈值由 BarConvTol 和变量尺度推导，写明推导过程。
   - 新增检查：储能、电池、氢储罐是否在同一时段既充又放，报告发生次数和量级。
   - 报告中注明：内点解可能把成本相同的等价方案分摊到多个选项上，解读时须留意。
