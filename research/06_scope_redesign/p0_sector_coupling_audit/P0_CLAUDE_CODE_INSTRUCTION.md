## 背景：新口径（推进版，待师哥最终确认）

1. 只比较两个极端：**互联 vs 完全不互联**；只用技术潜力；需求侧和供给侧的技术选择都交给模型内生优化。
2. **2050 年每个国家净零**（两个情景相同），允许 CCS、BECCS、DAC；覆盖全部能源相关 CO₂，包括工业过程排放、国内及国际航空航运。国际燃料舱单独报告，另做不计入的敏感性分析。
3. 跨境载体包括电、氢、氨、甲醇、合成燃料、LNG、CO₂。互联情景下东盟内部的这些网络内生优化；不互联情景下不允许任何东盟内部跨境基础设施。两个情景都可以按同一组外生世界价格从东盟外进口分子类载体：经现有/规划的接收站进入，扩建上限为 2.5 倍；只许进口、不许出口；价格做 ±20% 敏感性。
4. 数据必须可追溯；查不到的用自下而上推导（例如按排放反推行业能耗），推导过程要能复现。

这些口径与 Phase3 的冻结决定（`research/02_sector_coupling/phase3c/`）有多处不同。例如 Phase3 中：跨境 H2/gas/CO2 关闭、H2/NH3/甲醇进口推迟、Disconnected 保留区域共享的电力碳上限、FCEV 和船用氢不启用、工业为 Mode A。
