## S4A-1 风光资源与出力曲线（L14）

1. **审计现有出力曲线的生成链。** 写明以下各项，并逐项引用代码和配置位置：
   - 研究层或 pypsa-asean（基于 PyPSA-Earth）所用的 cutout：数据源、年份、范围；
   - 陆上风、海上风、光伏所用的风机或组件型号、轮毂高度；
   - 土地可用性（排除规则）；
   - 容量因子的计算方式；
   - 是否用了任何修正系数。
2. **与 PyPSA-Eur v2025.07.0 对照：** 默认风机型号（陆上、海上）、`resource_classes`、风速偏差修正（如有，例如基于 Global Wind Atlas 的修正）、可用性规则。逐项引用配置行和代码，列出差异。
3. **外部校验（国家级）：**
   - IRENA RPGC 2024 中各国新建陆上、海上风电和光伏的容量因子（凡有列出的国家都用，引用表号和页码）；
   - Global Wind Atlas 3.3 的国家级统计，通过公开接口只读获取，取不到就列入下载清单；
   - 列表对比模型的国家均值和节点最大值，以及这两组外部值。
4. **修正方案：**
   - 属于"与 PyPSA-Eur 默认做法对齐"的修改（如默认风机型号、资源分级），可以直接实施，设开关，原做法保留为对照。
   - PyPSA-Eur 默认做法以外的修正（如按 Global Wind Atlas 对风速做偏差缩放），只写成 PROPOSED，给出依据和对结果的影响估计，等用户决定。
5. **海上风电与台风区：**
   - 核查海上风电候选的范围（水深、离岸距离规则，按 PyPSA-Eur 规则并引用）。
   - 台风风险属于东盟特有问题，按工作原则第 3 条另行设计，包括抗台风机型的成本溢价或排除区。依据公开文献，写成 PROPOSED，不自行实施。
6. **重建并报告：** 重建出力曲线后，报告各国、各载体容量因子的分布（均值、分位数、各资源等级的潜力），与原曲线和外部值三方对比。

## S4A-2 存量机组补全（L15）

1. **对照数据：** 用 GEM Global Integrated Power Tracker 中各国、各类型的在运和在建容量，类型包括：煤、气、油、水电（含抽水蓄能）、地热、风、光、核、生物质。与网络中的存量机组逐类对照，生成覆盖率表。已知缺口：GEM 在运地热 ID 2,431.9、PH 1,937.0 MW，网络只匹配到约 1,323 MW。
2. **2050 年在役判断：** 按 S1 的寿命规则判断各机组 2050 年是否仍在役。没有投运年份的，标 UNRESOLVED，不默认纳入。
3. **补入网络：** 把在役的缺失机组补进网络，包括节点映射（按坐标找最近节点）、性能参数及其来源。参数来源依次为：technology-data v0.15.0、第 52 项的做法、AEO8，各自标明等级。
4. **报告：** 补全前后各国各类型的存量容量对比表。
5. **国内气田产量的节点分配**（S3 报告第 11 节第 8 项）：用 GEM Global Oil and Gas Extraction Tracker 的气田坐标和产量，替换 S3-1 中"按负荷份额"的 C 级分配。各国年产量上限仍为 UNSD 2019 值（第 43 项）。报告新旧分配的对比。
