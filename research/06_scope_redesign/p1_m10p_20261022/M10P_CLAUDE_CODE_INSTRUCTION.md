## 3. 事先登记的规则（写入 `RUN_PLAN.md` 与脚本，看结果前不得修改）

1. **时限：** 365×24h 每次 TimeLimit 21,600 s，墙钟 22,500 s。P1 墙钟 3,600 s。不重试，不改参数，不 warm start。
2. **验收：**
   - 按 GATES_V6：G1 = C1 (a)(b)(c)，G2 结构检查。
   - **阈值参照：** C1 (b)(c) 的分国阈值用本批 R1、R2 的分国差额（`batch_reference`）。R1、R2 完成前的运行先作临时判定，之后统一重评，保留 `grade_history`。
   - **停批：** 只有 C1 (a) 或 G2 失败才立即停批（第 138 项 D12）。
   - **对偶形式：** 恒等式误差 ≤ 0.01 bn，且每个参与者的残差影响 ≤ max(该参与者差额的 1 %, 0.01 bn)（第 138 项）。
3. **第四批档案选择（事先登记，第 133 项）：**
   - R3、R4 的 C1 (a)(b)(c) 全过，且与 R1、R2 的目标相对差都 ≤ 1e-5 → 第四批用 1e-6 T16；
   - 否则用档案 A；
   - 1e-5 档案不作备选。
4. **求解后处理（每次自动执行）：**
   - 违反量分析；
   - C1；
   - M12 分摊：对偶形式为主值，市场形式并列，α 区间；燃料舱作为参与者；
   - GATES_V6；
   - 登记 `EXPORTS.json`。
5. **批级后处理：**
   - B6；
   - 受益与比例规则对照；
   - 去一国检查：用 R1 作 c(N)，与 R5–R7 同档案同分辨率；
   - 敏感性差额：R8、R9 对 R2，R10 对 R1，R11 对 R2；
   - 第二级比较：R3、R4 对 R1、R2。
6. **无人值守：** 运行期间遇到任何问题，都按以上规则自行处理，不询问。规则没有覆盖的情况：停在安全状态，记录并等待。
