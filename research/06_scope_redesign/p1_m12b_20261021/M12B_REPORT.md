# M12b 报告：电网回路（KVL）是否破坏 Owen 分配的核心性质——本机 56×3h 去一国检验（第 139 项）

**摘要（判定：维持现有建模，跨境线路保留 KVL）**
1. **判定（按事先登记的规则）：全部 11 国违反量都为 0，都在容差内 → 维持现有建模。** 论文表述（指令原文）："定理对运输模型松弛成立，对真实电网在全部 11 国的去一国检验中成立（56×3h）"。第三批照原计划只做 3 次去一国作 365×24h 复核。
2. 违反是否存在：不存在。11 国的 Owen 对偶形式份额 φᵢ 都大于物理边际成本 c′(i) = c(N) − c(N − i)，余量从 +0.002 bn（BN，容差 0.010）到 +6.41 bn（ID）；市场形式也全部通过。α 区间下限处同样全部通过。
3. 量级：违反量全为 0。穿越国界回路被拆掉的 7 国中，最小余量为 MM +0.026 bn、TH +0.187 bn；余量与被拆回路数无正相关（Spearman −0.45，n = 11）。冒烟口径的数值没有科学含义，只用于本检验。
4. 运行：一体化运行复用 M08b 补充 01 再次冒烟（同一网络、同一档案、同一截断，已导出对偶所需文件），本步只求解 11 次。11 次中 10 次 optimal，去 SG 为 suboptimal（内点法停滞后返回，C1 全过）；11 次 GATES_V6 均为 ACCEPTED_LAYER2，右端项检查全部通过；Gurobi 墙钟合计约 2 h 04 min。
5. 第 138 项：对偶形式验收已改为 C1 同口径（恒等式 ≤ 0.01 bn，残差影响 ≤ max(1 % 差额, 0.01 bn)）。重评结果：S4O-6 不互联 false → **true**；S4N 试点 true → true；S4M-1 56×3h 冒烟 false → **false**（−0.018 bn）。
6. 备选方案"跨境交流线改为可控联络线"只做了评估、未实施：涉及 62 条交流线、约 8–10 个文件，属对 PyPSA-Eur 的结构性偏离（第 3 节）。按判定规则，本步不需要采用它。

## 3. 备选方案评估：跨境交流线改为可控联络线（只评估，不实施）

全文见 `evidence/M12B_ALTERNATIVE_ASSESSMENT.md`，要点如下。

- **方案：** 跨境 `Line` 改为不参与 KVL 的 `Link`，国内线保留 KVL。改后 KVL 回路全部在一国内部，去一国不改变其他国家的回路，Owen 定理对去一国联盟重新严格成立。
- **跨境交流线：** 62 条，分布在 12 个国家对（LA|TH 16、ID|MY 10、LA|VN 9、MM|TH 8、KH|VN 6、KH|TH 4、KH|LA / LA|MM / MY|TH 各 2、BN|MY / ID|TL / MY|SG 各 1），全部可扩建。存量 2,570 MW，单条扩建上限 20 GW。另有跨境直流链路 10 条（5 对 × 正反向），本来就是可控链路。改后每时段 KVL 回路由 71 个降到 18 个（纯国内：ID 9、MM 5、KH 3、TH 1）。
- **代码位置与工作量：** 现在没有任何"线改链路"开关。
  - 转换函数插在 `s2_network.py:385`（`apply_cross_border_switches_s2`）与 `:386`（`set_transmission_s2`）之间，须在 `pipeline_candidates` 与成本层之后、最大扩建与损耗步骤之前。
  - 需要改：`s4f_layers.py:63 / :87`（只处理 DC）；`s4j_layers.py` 损耗拆分；`s4l_layers.py` 零容量链路合并保护；`s4d_ledger.py`、`m12_allocation.py`、`m12_rhs_audit.py` 的按长度份额键（`Line:` 键会静默退回 0.5 / 0.5）；`s4m_cost_breakdown.py`；配置键与注册表。
  - 生产代码约 120–200 行，8–10 个文件；新测试文件约 100–150 行（INFERENCE）。
  - **语义差异：** AC 损耗代理（loss ≥ λ|s|，两端各半）与链路效率（受端扣 λ）口径不同。
- **对重建与测试的影响：** 新配置键改变配置哈希与 G2.2 子集哈希 → 四个网络、去一国变体、云端包都要重做，冒烟重跑；作为主算时 11 个读取冻结构建的测试需要更新期望。
- **与 PyPSA-Eur 的偏离：** PyPSA-Eur 对交流跨境线保留 KVL。本方案影响 71 个回路中的 53 个，属结构性偏离：经第三国的环流不再表示，倾向于高估互联价值。
- **结论：** 按事先登记的规则（全部在容差内）本步不需要采用；仍列为备选，交审阅端与用户决定。
