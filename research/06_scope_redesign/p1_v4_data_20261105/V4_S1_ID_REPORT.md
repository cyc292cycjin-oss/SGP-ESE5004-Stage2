## 0. 结论摘要

1. **基数（EXACT）：** S0 第 7.7 节的 269.32 TWh 是 UNSD 2019"未细分工业"煤行（硬煤 37,514.237 kt + 焦炭 57.8 kt，按上游系数）在 v3 扣水泥之前的值；扣掉水泥 2019 年能耗中的煤 27.96 TWh 后为 241.36 TWh（v2 口径），乘 v3 缩放系数 0.954658 后为 230.42 TWh（v3 等效）。指令中"v3 等效 633.14 TWh"实为 v2 口径，v3 等效是 604.43 TWh。另外，上游把印尼"硬煤"一律按 25.8 GJ/t 折算，而 HEESI 2025 在 2023 年之前用 24.67 GJ/t、之后用 20.29 GJ/t（B，热值口径问题，见第 1.1 节）。
2. **自备电厂用煤确实记在工业里（VERIFIED + INFERENCE）：** UNSD 2019 年自备电厂（autoproducer）发电量 44,798.87 GWh，但记在转换项下的燃料（煤 1,694 kt、气 45,799 TJ、柴油 664.6 kt）合计只有 32.80 TWh，即便效率 100 % 也发不出这么多电（EXACT 不等式）；HEESI 2019 年"发电"类售煤 98.55 Mt 恰等于 UNSD 电厂转换投入（主营 96,856 kt + 自备 1,694 kt），2019 年 HEESI 装机表里没有自用煤电（自用 IUPTLS 煤电 2024 年起才单列，2025 年 13,820 MW），同年非 PLN 工业用电 43,709 GWh。IEA 文档第 471 页的印尼说明与此一致（只作方法依据）。
3. **自备用煤量（PROPOSED / C）：** GEM GIPT 2026-09 的"Captive Industry Type"字段给出 2019 年末在运自备煤电 79 台、5,924 MW（年均 5,239 MW），其中镍 2,572、造纸 1,601、化工 460 MW。按出处可查的利用小时（3,589 / 5,141 / 5,868 h）与 PLN 煤耗（0.540 / 0.561 / 0.628 t/MWh），2019 年仍留在工业行内的自备用煤为**低 60.63、中 96.08、高 156.53 TWh**（模型热值口径），占"未细分工业"煤行的 23 % / 36 % / 58 %。交叉核对（HEESI 造纸售煤、BPS 造纸自发电、全国自上而下余量 16.8–19.0 TWh 电）表明高档不成立、中档高估造纸；**建议中心值 75.89 TWh（镍取中档、其余取低档，占 28 %）**。
4. **与 v3 显式子部门的重复（INFERENCE / C）：** v3 的镍按 Wei 2020 计电 11.33 TWh（2019），由电网供应；而供这部分电的自备煤仍在"其他"桶里当高温热。中心值下，2050 年"其他"桶中约 **102.7 TWh** 的有用热对应显式子部门的自备发电燃料（镍 94.7、水泥 5.5、钢 1.6、氧化铝 0.9 TWh）。GIPT 镍自备发电量（中档 10.47 TWh）与 Wei 口径的 11.33 TWh 相差 8 %，两条独立来源互相印证。

6. **钢（VERIFIED / C）：** 2019 年 GEM 在运产能 14.4 Mt，按 USGS 8,565 kt 与 worldsteel 2019 转炉 / 电炉比例校准，u = 0.70 / 0.65。设施法（JRC-IDEES 现状口径）14.93 TWh，比 UNSD 钢铁行扣除高炉焦炭与喷吹煤后的 32.57 TWh **低 54 %，超出 ±20 %**；差额几乎全在 UNSD 钢铁行的天然气 27.68 TWh，BPS KBLI 2410 用气只有约 0.5 TWh，查不到来源，记入差异表，未强行校准。2024 年 worldsteel 18.64 Mt 需要 u = 1.19，即约 **2.81 Mt 的全国产量不在 GEM 设施内**（推断为莫罗瓦利不锈钢）。2050 年设施合计 58.56 TWh，对 v3 57.96 TWh 差 +1.0 %（在 ±5 % 内，差额是 v3 冲抵的氯碱副产氢）。节点份额：Java-Bali1 0 低 15.0 个百分点、Sulawesi0 3 高 12.1 个百分点（Krakatau Steel 与 GRP 的实际产量远低于产能，德信钢铁按 u = 1.19 计）。
7. **水泥（VERIFIED / C）：** 2019 年设施法 62.23 TWh 对 v3 扣除量 74.19 TWh 为 −16.1 %（在 ±20 % 内）；2050 年与 v3 相同（97.64 TWh）；节点份额与 v3 完全一致。v3 偏高 19 % 的来源是熟料比：EDGAR 2.A.1 ÷ 0.52 得熟料 56.50 Mt，是 USGS 2019 水泥 71.9 Mt 的 0.786 倍，而 v3 用欧洲技术数据的 0.656 把熟料折回水泥（86.13 Mt）。窑燃料按熟料算本身合理，偏高的只是粉磨电（修正 ii：−1.52 TWh）；若改按"USGS 水泥 × 0.656"（修正 i：−12.25 TWh），守恒式下 2050 年"其他"桶 +29.41 TWh。两种修正都只量化未实施。
8. **镍基年（VERIFIED）：** v3 主算 2050 年镍活动量 868 kt Ni 只有 USGS 2023 年实际产量 1,676 kt Ni 的 52 %，**审阅端的推断成立**。"镍改用 2023 基年"（只换镍）使 ID 镍 2050 年 49.97 → 162.65 TWh，守恒式下"其他"桶 −112.68 TWh。2023 年另有 MHP（高压酸浸）18 万 t Ni 不在 v3 路线内。Wei Case 3 是含镍 35 % 的镍铁，印尼 NPI 含镍 11.9 %（2019）/ 14.0 %（2023），按每吨合金单耗换算会使每吨镍能耗最多高 2.5–2.9 倍（方向向上，上界）。
9. **BPS 制造业统计（VERIFIED）：** 2019 年 IBS 表是矢量文字，从页面表单对象逐字形读出；表 5.1 与 6a.1 共 2,379 项上下级核对，**0 项超过 0.5 %**（2,053 项吻合，其中 5 项有印刷取整差；326 项因子行"*"不公布只能作下界）。IBS 合计只覆盖 UNSD 2019 ID 工业的 12 %（煤 5 %、油 25 %、气 15 %、电 44 %、生物质 0），镍冶炼与大钢厂的能耗几乎不在其中；化工行的气和电与 UNSD 化工行几乎相同（102 %、101 %）。
10. **"其他"桶拆分建议（PROPOSED）：** 2019 年 633.14 TWh（v2 口径）中，自备电厂用煤 70.78（中心值）、v3 显式有色 28.25、IBS 可归属 52.83、甘蔗渣 13.38 TWh，**余量 467.90 TWh（74 %）**。余量中的 148.54 TWh 来自 UNSD 一条"燃料木材—未细分工业"记录（6,525 万 m³），而 HEESI 2019 年工业生物质只有 0.905 TWh，数据冲突，须用户决定。

**单耗出处与适用工艺（VERIFIED 出处，INFERENCE 判断）：** Wei et al. 2020 表 8 Case 3-FeNi 是回转窑—电炉（RKEF）生产含镍 35 % 的镍铁：电 7,237 + 1,081 kWh/t 合金、干燥与焙烧天然气各 308 kg、无烟煤还原剂 569 kg（采矿不计），折合每吨镍电 23.77、燃料 37.54 MWh。印尼 2019 / 2023 年 NPI 含镍 11.9 % / 14.0 %（USGS 毛重与含镍量之比），镍铁约 20 %。若每吨合金能耗相近，每吨镍能耗应高 2.5–2.9 倍（上界；实际取决于矿石品位与渣量，方向向上）；v3 的 NIUPPER 敏感性（26 MWh/t NPI 毛重 = 219 MWh/t Ni）也在这个方向。镍锍（多由 NPI 吹炼而来）的额外能耗、MHP（高压酸浸，蒸汽与酸为主）都不在 Case 3 内。另一方面，第 1 节 GIPT 镍自备发电（中档 10.47 TWh）与 Wei 口径的 11.33 TWh 接近，说明 2019 年的用电强度不至于偏离太远（但这部分自备电也供应园区内的不锈钢冶炼）。

### 4.1 解析与对账

### 4.2 折算（HEESI 2025 附录 03，PDF 第 170 页、印刷页 154）

汽油 kL × 5.8275 BOE（Premium）；柴油 kL × 6.4871（Gasoil）；煤 t × 4.2000（加里曼丹煤，2023 年前使用；平均煤 3.4554 作敏感性，另列模型的 25.8 GJ/t）；型煤 t × 3.5638；天然气 m³ × 0.0353147 MSCF/m³ × 0.1796 BOE/MSCF（PGN 与非 PGN）；LPG 升 × 0.54 kg/l（本机没有密度出处，C）× 8.5246 BOE/t；BOE = 5.873 GJ。润滑油属非能源用途，只列升数。终端用电 = 购入 + 自发 − 售出。
