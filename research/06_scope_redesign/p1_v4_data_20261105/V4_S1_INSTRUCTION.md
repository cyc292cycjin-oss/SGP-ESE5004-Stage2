## 1. 自备电厂用煤（A，最先做）

目标：量化 ID 2019 年"其他"桶中的煤里有多少其实是自备电厂的发电燃料，并给出处理选项。

1. **先核清基数。** `V3_OTHER_BUCKET_UNSD_ROWS.csv` 中 ID `other` 行 2019 年煤为 241.36 TWh（v3 等效），S0 第 7.7 节写的是 269 TWh。说明两者差在哪（扣减前后、口径或单位），后文统一用哪个数。追溯到 UNSD 2019 原始交易项：ID 工业煤由哪些交易项、哪些煤种组成。
2. **UNSD 本身：** ID 2019 是否有自备电厂（autoproducer）发电的煤投入或发电量行（交易项名称以导出文件为准）。若为 0 而 GIPT 显示有在运自备煤电，即为"自备用煤记入工业消费"的直接证据。
3. **HEESI 2025（已在库）：** 工业煤与发电煤怎样记；有没有自备电厂、非 PLN 发电或"captive"的表或注释。
4. **GEM GIPT 2026-09（已在库，位置见 `DOWNLOAD_LIST.md` 第 20 行）：** 列出 ID 煤电机组中的自备机组（优先用文件里的 captive 字段；没有该字段时说明识别方法，如所有者、工业园区、坐标匹配，并给出识别清单供人工抽查）。按投产年份算 **2019 年在运**自备装机，按服务行业分（镍等金属冶炼、造纸、水泥、化工、其他）。
5. **2019 年自备用煤估算：** 装机 × 利用小时 ÷ 效率，给低、中、高三档。利用率与效率的取值必须有出处（GEM、CREA/GEM 报告、文献），不能凭经验填；等级标 C 或 B。
6. **交叉核对：**

8. **处理选项（只量化，不实施）：** 设自备用煤为 C、发电效率为 η。
