## 2. 追加的只读任务：风电为 0 的原因诊断（R12 第一部分）

S1 本机部分完成后再做。只读，不修改任何文件。

用现有的 D 阶段网络和成本层（`gate6_2920_candidate_UNQUALIFIED.nc`、`model_cost_layer.json` 及其源 CSV）回答：陆上和海上风电在两个模型中装机都是 0，原因是什么。

逐项检查，每项都给出数值和证据路径：
1. 各节点 `p_nom_max` 是否为 0 或很小；
2. 出力曲线 `p_max_pu` 的年平均容量因子按国家的分布；
3. 资本成本与 technology-data 对应行是否一致，有没有单位或年份错误；
4. 风电相对光伏的平准化成本比较：用模型里实际的参数算；
5. 是否存在约束或配置把风电挡掉（例如 extendable 设置、land use 约束）；
6. 与外部参考比较：东盟各国陆上风电的典型容量因子，用文献或 Global Wind Atlas 的公开值，写明来源；查不到的标"未核实"，**不得估算**。

结论分三类之一：
- 数据或代码错误：需要修正，指出位置；
- 经济上合理：风资源差或成本高，模型选择不建风电是正常的；
- 无法判断：说明缺什么证据。
