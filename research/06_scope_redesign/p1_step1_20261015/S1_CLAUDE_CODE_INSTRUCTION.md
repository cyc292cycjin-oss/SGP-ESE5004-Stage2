### S1-4 发电与储能候选（R2 中不依赖生物质和 CO₂ 封存的部分）
- **核电（大型压水堆 + SMR）：**
  - 新建候选生成器，不受"只在已有同类电厂的母线建候选"这条上游规则（`add_electricity.py:772`）限制；
  - 选址允许表放在配置文件中，作为 C 级假设登记，初始版本为：大型堆允许所有节点但不含新加坡，SMR 允许所有节点；
  - 大型堆成本取 technology-data `nuclear`。technology-data 里的 "SMR" 指蒸汽甲烷重整，**不是小型堆**，所以 SMR 成本数据暂缺。SMR 候选先建好结构，设 `p_nom_max = 0`，并标记 `DATA_PENDING`。
- **地热、新增水电、抽蓄（按站址）：** 结构同上，潜力数据未到之前设 `p_nom_max = 0` 并标记 `DATA_PENDING`。成本取 technology-data。
- **氢燃气轮机、燃料电池、储氢罐、电池、户用电池：** 接通，并确认在两个情景里都可以扩建。
- **成本缩放系数：** 每类技术一个，默认 1.0，作用在 `capital_cost` 上。验证：全部为 1.0 时，网络文件哈希与不加这一层时完全一致。
- **本步不做：** 生物质发电（第二步）；燃气 CCS（第二步，依赖 CO₂ 封存）；漂浮式海上风电（需要重算出力曲线，归入 R12 数据核查）。

  - B5：两个情景只差一个开关，不互联情景的跨境容量和流量全为 0；
  - B6：一体化情景的总成本 ≤ 不互联情景。注意存量跨境资产不能计资本成本，只计 FOM，与研究层对存量机组的处理一致。PyPSA 对可扩展线路按全部 `s_nom_opt` 收取资本成本，所以应把存量部分建成不可扩展组件，新增部分另建可扩展组件。否则一体化情景会为沉没资产付费，B6 可能出现假失败；
