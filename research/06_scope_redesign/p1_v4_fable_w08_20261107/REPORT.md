### 4.2 LP 凸性上下界：前提、分类、补全、结论

**规则（EXACT）：** 对 min c'x s.t. Ax = b、x 的上下界也视为右端，最优值 V(b) 对 b 凸，任一最优对偶 y(b) 是次梯度：V(b′) ≥ V(b) + y(b)'(b′ − b)。两端取对偶得 y_v31'Δb ≤ ΔV ≤ y_v4'Δb。成立的前提：两端是**同一个 LP**（同 A、同 c、同变量集），只有 b 不同；对偶是精确次梯度。

**本案中哪些变动属于右端（VERIFIED，`compare_off_build.py` 与 `net_check.py` 的组件比较）：**
- 右端：负荷 p_set（含 457 条时变负荷，逐时段）；池 e_initial（能量平衡 t = 0 的右端）与 e_nom（上界）；国产气年度上限（`external_annual_caps`）；EV 电池 / 充电桩等非可扩容量（上界）；过程排放负荷；删去的组件（油棕纤维池、5 个 ID 煤母线与外部煤发电机）在数学上等价于把其上界置 0——仍是右端。
- **不是右端：** 气生产交付链路的逸散系数（`efficiency2`，矩阵 A 的系数；基准 gross → marketed 使系数变 +0.1–23 %）；v4 新增的终端母线与链路（结构）。前者 W08 在一阶估计中列为"未计入"，在括号中也未计入；量级（INFERENCE）：Δ逸散 ≈ 国产气量 × 系数变化 ≈ ID 0.5 Mt/a 级，乘碳价后 ≈ 0.05 bn，远小于区间宽度。后者 W08 以"同国同载体母线均价"补全（15.29 TWh，INFERENCE，且这些母线是效率 1 的计量母线，等价于右端）。
- **目标常数项：** `--scaling on` 把固定运维与沉没成本移出 LP 再加回；本审查核对三次一体化解的 objective − objective_lp = 2,370,402,134.80 EUR 完全相同（`evidence/SMOKE_DECOMP.json`），所以 ΔV(总) = ΔV(LP)，括号用总目标值差没有问题（v4_F2 的常数 2,541,079,190.89 与 v3.1 F2 比较时同理成立，未逐位核对）。

**补全项是否完整：**
- 删去的池：W08 用"母线均价 − 储能边际成本"。零容量放电型储能的精确次梯度是 max_t(λ_t) − mc（能量可择时放出）；本审查核对 ID 固体生物质母线价格在 56 时段内恒定（v3.1 58.1761、v4 45.5671，max − min ≈ 1e-9），所以均价 = 最大价，补全**精确**（`evidence/SMOKE_DECOMP.json`）。
- 固定容量按 Σ|上界对偶| ✓；气上限按年度约束对偶 ✓；新母线负荷按同国同载体均价（INFERENCE）；补全后 0 MWh 未计价 ✓。
- 未计：逸散系数（≈ 0.05 bn，见上）；v3.1 无对偶的新组件（W08 已列）。
- 对偶精度：barrier 1e-6 相对间隙、无交叉，对偶是近似次梯度；相对间隙 × 目标值 ≈ 0.33 bn 是括号应带的容差。三对实际差距边界最近处为 R1 上界 12.33 − 8.14 = 4.2 bn，远大于容差。
- 下界：v3.1 的 VN 池对偶退化（2,929 / 28,394 EUR/MWh）使负荷项与池项各约 ±31 bn 相抵，下界几乎无信息（R2 −30.6）；数学上仍有效（退化面上任一对偶都是次梯度）。

**结论是否站得住：** 站得住，且在本案中几乎精确；但它只证明"两次求解与 LP 凸性不矛盾"，是**必要条件**：区间 [−0.57, +12.33] 宽 12.9 bn，对一个 8.1 bn 的差没有分辨力，任何在区间内的数都"通过"。审阅端第 7 条把它定为"必要而非充分"、以检查点 0 差为主证据，本审查同意；建议不要把它写成通过 / 不通过的门，而作为"若违反则必有错"的报警线，并随结果同时报告两端的分项（第 4.3 节）。

### 4.3 "v4 成本上升主要来自生物质潜力下调"的依据与缺口

**审阅端的依据（第 9 条）：** 上界分项——删去的油棕纤维池 +8.59、其他池 +4.47、负荷 −0.37 bn（主算一体化）。这是在 v4 对偶处的一阶分解；在 v3.1 对偶处同样的分解是负荷 −31.2、池 +30.8（含 VN 退化 15.8；去掉 VN 后池约 +15.0、负荷约 −12.5）。分解依赖评价价格：**潜力项在两端都为 +13 ～ +15 bn（稳健），需求项在两端为 −0.4 ～ −12.5 bn（不稳健）**，所以"潜力下调是主要正项"成立，"需求下降抵消多少"不能由一阶分项定。
