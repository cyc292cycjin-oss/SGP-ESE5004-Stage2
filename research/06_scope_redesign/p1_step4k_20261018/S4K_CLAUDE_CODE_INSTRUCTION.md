## S4K-1 交流线性损耗代理

1. **先读 PyPSA 0.30.3 的 `transmission_losses` 实现**（损耗变量的定义、在节点平衡中如何分到两端、与基尔霍夫约束的关系），引用文件与行号。新代理沿用同一结构，只把分段切线换成线性下界。
2. **形式：** 对每条交流线 l（存量与候选、国内与跨境、两个情景同一规则）和每个时段 t，引入损耗变量 ℓ_{l,t} ≥ 0，约束 ℓ_{l,t} ≥ λ_l·p_{l,t} 与 ℓ_{l,t} ≥ −λ_l·p_{l,t}；损耗在 bus0 与 bus1 各计一半，作为消耗进入节点平衡（与 PyPSA 做法一致）。另加上界 ℓ_{l,t} ≤ λ_l·s_max_pu·s_nom_l（s_nom 为容量变量时按变量写），以收紧可行域。求解时 `transmission_losses` 设为 0，避免重复计算。
3. **λ 的计算（逐线，按线型）：** 一回线电阻 R = r_per_km × L（Ω），参考电流 I_ref = α × s_max_pu × i_nom（kA），λ = √3 × I_ref × R ÷ v_nom（v_nom 以 kV 计）。主算 α = 0.5（参考负载为一回线允许负载的一半）。用本模型 380 kV 四分裂线型核对：100 km 时 λ 应约 1.2 %（α = 0.5）、约 2.5 %（α = 1.0）；若相差超过 20 %，停下报告。L 用模型中的线路长度（已含长度系数 1.25）。
4. **开关：** `research.network.ac_losses: linear_proxy`（主算）| `pypsa_tangent`（S4J 状态，对照）| `none`；`research.network.ac_loss_reference_loading: 0.5`（主算，敏感性 1.0）。直流与管道损耗维持 S4J 不变。
5. **账本：** 损耗按所在节点电价计入；跨境线路的租金（含损耗）沿用 50/50 规则；核对 B16 恒等式成立，写明计算式。
6. **报告：** λ 的分布（按国内 / 跨境、按国家对），以及与 S4J 切线近似在若干流量水平下的损耗对比。注册表登记为对 PyPSA-Eur 的偏离：理由是候选线扩建幅度远超 PyPSA-Eur 常见情形，固定电阻下的切线近似失真；回路数随流量增加时每回路负载大致不变，损耗近似与流量成正比，与直流按长度计效率的口径一致；不采用迭代更新电阻（`skip_iterations: false`），因其需多次求解，对联盟研究不可行。
