## 0. 结论

1. **审阅端的怀疑成立。** 365×24h 网络由 `daily_resolution.to_daily` 从 2920×3h 网络取每天 8 个值的算术平均得到；EV 电池的早晨下限在 3 小时网络里每天只有 1 个时段是 0.8、其余 7 个是 0，平均后**每天都是 0.1**。PyPSA-Eur（本机上游代码）对 Store 的 `e_min_pu` 取最大值，日分辨率下仍是每天 0.8。全部网络中只有这 96 个 EV 电池有时变储能边界，所以这个放松只作用在 EV 上。（VERIFIED）
2. **V1 把车队电池当跨日储能用满了。** 96 个电池全部触到 0.1 和 1.0；按 `e_nom` 加权 71.9 % 的电池·日电量低于 0.8；全系统合计电量有 332 天低于 0.8，最长连续 89 天；全年跨日正变化 154.7 TWh，约 19.5 次等效满循环。下限若是 0.8，跨日可用带宽只有 1.59 TWh，现在是 7.14 TWh。（VERIFIED）
3. **V5 − V1 = 5.13 bn 基本都来自这块跨日储能。** 日分辨率下没有日内渠道，固定式电池两次运行都是 0 GWh。V1 中 EV 电池的租值为 1.95 bn，按线性规划的凸性，这是电池价值的下界。若按上游的最大值规则聚合，日分辨率下的 EV 效应应在 **1.14–3.61 bn** 之间，也就是说，平均聚合造成的放松贡献了 5.13 bn 中的 **1.52–3.99 bn（30–78 %）**。（数字 VERIFIED，归因与区间 INFERENCE，见第 6.1 节）

5. **56 时段冒烟保留了下限，但冒烟的 EV 效应 +10.28 bn 与筛查的 5.13 bn 是两种不同机制。** 冒烟中电池吞吐的 99 % 以上是日内转移，早晨到早晨的跨日变化只占约 0.5 %；筛查中全部是跨日。另外，冒烟的 Store 权重是 156.4 h，电池每个时段最多只能平移约 51 GW（真实 3 小时约 2,645 GW），所以冒烟也不能作为 2920×3h EV 效应的定量参照。（VERIFIED / INFERENCE）

1. 365×24h 的下限是 0.1，上游规则下应为 0.8（第 1、2 节，VERIFIED）。
2. V1 用满了 0.1–1.0 的带宽：每个电池都触到两端，七成以上电池·日在 0.8 以下，单个电池最长连续 126 天、全系统 89 天，19.5 次等效循环（第 3 节，VERIFIED）。在 0.8 下限下这些轨迹都不可行。
3. 日分辨率下没有日内渠道；V5 − V1 的成本差全部落在替代多日储能的技术上，固定式电池两次都是 0（第 4 节）。
4. **租值下界与区间：**
   - 车队电池无损、循环、零成本（`standing_loss` 0、`e_cyclic` True、成本 0，VERIFIED）。这样的电池把电量整体平移一个常数不改变线性规划，所以 [0.8, 1.0] 的带宽**等价于**把现有 [0.1, 1.0] 带宽按 s = 0.2 / 0.9 = 0.222 缩放（EXACT）。
   - 记 B(s) 为电池按 s 缩放后相对"无电池"的成本节省。线性规划的最优值是右端参数的凸函数，所以 B(s) 是凹函数；B 在 s = 1 处的斜率等于电池租值 1.952 bn（对偶）。
   - 取 B(1) ≈ V5 − V1 = 5.1295 bn。近似之处：V5 的 EV 负荷是恒定值，而"无电池的 E2"还留有星期形状（UTC 日 0.936–1.028 倍，最大偏离 5.3 GW），充电桩容量在日分辨率下不起约束。这部分差异小（INFERENCE）。
   - 于是：上游最大值规则下的日分辨率 EV 效应 B(0.222) ∈ [0.222 × 5.13, 5.13 − 0.778 × 1.95] = **[1.14, 3.61] bn**；平均聚合造成的部分 = 5.13 − B(0.222) ∈ **[1.52, 3.99] bn，即 30–78 %**（`evidence/evdiag/EV_CHECKS.json`）。
   - 区间宽，是因为不求解就不知道 B 的曲率。另外，即使按上游规则，0.2 × `e_nom` 的跨日带宽仍可能值到 3.6 bn。所以第 15.5 节"|V5 − V1| < 2 bn"的预测在上游规则下也未必成立，它的前提"日分辨率看不到 EV"只对日内部分成立。

### 6.2 2920×3h 正式路径是否受影响

**不受影响**（VERIFIED）：正式网络由 `apply_ev_structure` 直接按 3 小时生成，下限 0.8 每天一个时段，与上游最大值规则逐时段一致；`no_new_xb` 2920×3h 由一体化派生，下限逐值相同；正式路径不调用 `to_daily`。正式运行中，车队电池可以在一天之内自由转移全部 EV 用电（7.93 TWh 远大于一天的 1.96 TWh），跨日只能在早晨电量 0.8–1.0 之间转移，即 1.59 TWh。

一个细节（只记录，不建议改动）：+6.5、+7 区的下限作用在当地 9:30、10:00，比逐小时口径的 8:00 晚 1.5–2 小时（第 2.3 节）。这与上游在 3 小时网格上的结果相同。

### 6.3 对筛查结论的影响

- **修订桥：** V5 → V1 这一步的 −5.13 bn 不能读作"EV 智能充电的效果"。它是日分辨率下一块 7.14 TWh 零成本跨日储能的价值，其中 1.52–3.99 bn 是聚合方式造成的。v2 → v3 的总变化 −7.19 bn 因此也被高估了同样的量。
