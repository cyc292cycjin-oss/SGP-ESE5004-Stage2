# X1 停止说明：S8 无法给出"运营中"存量

依据 `V3_REVIEW_DECISIONS_PHASE3.md` X1 的停止条件："若 S8 的口径（运营 / 规划）无法确认，停下报告"。**本步未改网络和代码，未重建，未求解，本补充 Gurobi 额度 0 / 4。** 第 2 步也未开始。

## 1. 为什么停（VERIFIED，原始 PDF）

X1 要求以 S8 为唯一来源，且只计运营中、在建不计。两个条件同时满足不了：

| 来源 | 表 | 对这组数的说明 | 逐行状态 |
|---|---|---|---|
| Zhong et al., iScience 2025 SI，`mmc1.pdf` 第 11–12 页 | Table S8 | 表前说明：运营中的加上在建的 | **无**，只有线路、容量、长度、类型四列 |
| Zhong et al., PNAS Nexus 2026 SI，`pgaf389_supplementary_data.pdf` 第 11–12 页 | Table S4 | 表名为"规划中的输电线路"；正文说含已有、在建和规划，规划总容量 29.75 GW | **无** |

同一组数字，一处说运营加在建，另一处说已有、在建加规划。S8 的口径因此**无法确认**，而且就算接受 iScience 的说法，表里也没有办法把"运营中"逐对拆出来。S8 也不区分 AC / DC，只分陆上、海上。

## 3. 这个决定为什么重要（只读，来自上一轮 `no_new_xb` 冒烟）

`evidence/X1_CORRIDOR_LOADING_NO_NEW_XB_56.csv`。一月一周的 56 时段，档案 A，只能看相对大小。

| 走廊 | 可用容量（s_nom × 0.7） | 绑定的线·时段比例 | 平均影子价格（EUR/MWh） |
|---|---:|---:|---:|
| **LA–TH**（9 条） | 668.5 | 34 % | **531** |
| ID–MY | 161 | 82 % | 38 |
| MY–SG | 367.5 | 80 % | 35 |
| LA–MM | 21 | 64 % | 33 |
| KH–LA | 210 | 30 % | 23 |
| KH–TH | 175 | 50 % | 22 |
| MY–TH | 656 | 74 % | 18 |
| KH–VN | 140 | 77 % | 17 |

- LA–TH 的影子价格比其他走廊高一个量级以上。LA 有 9.76 GW 水电机组和 4.66 GW 径流水电，平均负荷只有 4.14 GW，外送可用容量却只有约 0.9 GW（TH 668.5 MW，KH 210 MW，MM 21 MW）。影子价格是单条线的值，受 KVL 环流影响，只作相对比较。
- 所以审阅端关注 LA–TH 是对的：现实中老挝对泰国的电站专线不在 955 MW 的电网联络线之内（INFERENCE，无原始表），模型把这部分水电压住了。但 S8 的 6,770 MW 含在建，也不能直接当运营值。
- 线路容量系数 0.7 对所有交流线都生效，如果存量改动，实际可用值也要乘 0.7。

## 4. 选项（科学决定，由用户作出）

| 选项 | 做法 | 代价 |
|---|---|---|
| **A（建议）** | 主算以 APG existing 为唯一来源，也就是现网 2,870 MW。这是工作区唯一有逐行"现有"列的表。X1 改为登记来源，不换值。LA–TH 专线另作敏感性 | 改了审阅决定的来源；LA 水电外送仍受限。不用为 X1 重建，只需构建 flat 网络 |
| B | 取得能逐线路区分状态的原始来源（IEA 2019a/b，或 EGAT / EDL 项目表），逐对判定后替换 | 最准确；需要用户提供或授权下载，时间不确定 |
| C | 只对 LA–TH 另行取值，其余按 APG | 能缓解最紧的走廊，但没有来源能给出运营口径的 LA–TH 值，S8 含在建；若用 6,770 须写明高估风险 |
| D | 按 S8 全量替换 | 与"在建不计"矛盾，TH–MM 14.86 GW 进入存量；不建议 |

我建议 A：它满足"只计运营中"和"单一来源"这两个核心要求，只是把来源从 S8 换成 APG；LA–TH 留待有来源后做敏感性。若审阅端认为 LA–TH 必须在筛查前解决，就选 B，只针对 LA–TH 和 KH–TH 取数即可。
