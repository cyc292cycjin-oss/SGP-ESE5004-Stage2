### 1.1 定义（第 230 项第 0 节；实现为 `coalition_subnetwork(..., include_bunker="ports")`）

- 燃料舱参与者按加注港所在国拆成子参与者 B_i（i 国港口与机场节点上的燃料舱负荷），并入 i 国：合并博弈 x_i^m = x_i + x_{B,i}。
- 联盟 S 的燃料舱部分只含成员国节点上的燃料舱负荷（连同其终端母线、由本国国家液体母线供给的非化石航煤计量链路、化石航煤计量链路与甲醇供给链路）；燃料舱净零账户只连成员国节点的化石计量链路（账户 ≤ 0 不变：钩子按每条剩余计量链路 × 每个时段写成"流量 = 0"）。非成员国节点上的燃料舱组件随非成员国移除（规则 R3）。其余规则（R1、R2、R4–R6，端口规则下的过境保留）与 W20 相同（`work/p1_v4_w20_20261109/COALITION_BUILD.md`）。
- **R0：** 全部 11 国、不含燃料舱（`include_bunker=False`，W20 规则：燃料舱负荷、终端母线、计量链路、账户与钩子全部移除）。
- **x_{B,i}（第 2.3 条，VERIFIED，`BUNKER_PORT_ALLOCATION.csv`、`evidence/W20B_BUNKER_PORT_ALLOCATION.json`）：** 从 W20 所用的 56 时段一体化解（D2c 冒烟 R1 = W14 冒烟）按 M12 同一代码路径求对偶形式：x_{B,i} = Σ（i 国节点上燃料舱母线的节点平衡行）y × 右端项中燃料舱部分。重建 LP 与导出 LP 的行列标签集合相同、节点平衡右端项偏差 0；**Σ_i x_{B,i} − x_B = 0.000 EUR**（≤ 0.01 bn：通过）；燃料舱的非节点行（每计量链路净零行，右端 0）、列界项与目标常数项均为 0；市场形式之和与 OWEN 市场形式差 −0.03 EUR。

### 1.3 c(S) 与 x(S)

- **c(S)：** 该网络 56 时段求解的目标值（含目标常数项，`SOLVE_RECEIPT.json` 的 `objective`；与 Owen 份额加总所对的一体化目标值同一口径）。
- **R0：** x(N∖B) = 11 国对偶形式份额之和 = **277.4656 bn**（D2c 冒烟 R1 的 `m12_owen/OWEN.json`，α 0.5；与 W20 相同）。**D = c(N∖B) − x(N∖B)。** x(N∖B) ≤ c(N∖B) ⇔ D ≥ 0 ⇔ 燃料舱至少支付其增量成本：c(N) = 目标值 = x(N∖B) + x_B − 4,519 EUR（对偶形式残差），故 x_B − [c(N) − c(N∖B)] = D + 4,519 EUR。
- **按港口的 17 个联盟：** x^m(S) = Σ_{i∈S} (x_i + x_{B,i})，x_i 取同一 OWEN.json（α 0.5），x_{B,i} 取第 1.1 节。**恒等式核对（EXACT）：** 11 国合并份额之和 363,190,034,301.60 EUR − 目标值 363,190,038,821.08 EUR = **−4,519.48 EUR**（≤ 0.01 bn：通过）。
- **α 区间：** 只有一端在 S 的跨境国家对随 α ∈ [0, 1] 变化（x_{B,i} 不含国家对项），x^m(S) 在 x^m(S, 0.5) ± 0.5 Σ|v| 之间。
- **市场形式（并列报告）：** x_i^市场 + x_{B,i}^市场（燃料舱市场形式 = 节点价格 × 负荷 × 权重，按节点国家拆分）；不受 Owen 定理保证。
- **D8 加回（并列报告，不作判据）：** 与 W20 相同（被移除的边界存量设施 α 0.5 份额 FOM）。

### 1.4 判定（第 139 项，事前登记；`scripts/w20b_eval.py`）

- 违反量 x(S) − c(S) **> max(1 % × c(S), 0.01 bn)** 才算违反；在此之内记为"在容差内成立"（WITHIN）；x(S) ≤ c(S) 记为"严格成立"（STRICT）。判据只用对偶形式 α 0.5；α 区间最不利端点、市场形式、D8 加回并列给出。R0 同一规则。
- **任一违反：停下交审阅端**，不改模型、不改参数、不重试，其余运行不再求解（运行器每次求解后按本规则判定）。
- **非 optimal：** 记录终止状态与 Gurobi 状态，不重试，继续下一个；返回了目标值的非 optimal 运行同样判定并标注（若显示违反，也停下）。**不可行：** 先查结构原因（`STATIC_CHECKS_W20B.json` 的 `sinks` 与 `bunker.liquid_sources`：成员国的 CO₂ 去向、液体燃料与燃料舱供给来源），属结构原因的记为 c(S) 不可达、条件平凡成立，不计为违反，并写明。
- **供解读（不作判据）：** 余量 / 该联盟合并 Owen 受益 B^m(S)（去一国另报余量 / 被移出国家 i 的 b_i^m；b_i^m = b_i + b_{B,i}，b_{B,i} = x_{B,i}(不新建跨境) − x_{B,i}(一体化)，严格口径，第 230 项第 0 节）；与 W20 同国家不含燃料舱的余量对照：
  - **恒等式（EXACT）：** 合并余量 c^m(S) − x^m(S) = [c_W20(S) − x(S)] − D_S，其中 Δ_S = c^m(S) − c_W20(S)（联盟 S 自己供给其燃料舱的增量成本），**D_S = x_B(S) − Δ_S**（S 的燃料舱按一体化对偶价支付、超出其在 S 内增量成本的部分）；S = N 时 D_N = D（R0 测出）。

### 1.5 预期

- **审阅端（第 230 项）：** 18 个条件全部成立；R0 的 D 在 3.5–4.1 bn；合并后余量最小的仍可能是非 GMS 与去 TH / MM，但为正。
- **执行方（INFERENCE，不作判据）：**
  - **R0：** D ≈ 3.79–3.81 bn（W20 由去 BN / 去 TL 反推，`work/p1_v4_w20_20261109/REPORT.md` 第 0.1 节第 1 条）；D ≥ 0 在矩阵博弈中由 Owen 定理保证（把燃料舱负荷置零只改右端项），物理上移除燃料舱组件与置零等价（终端母线无其他出口），所以预期严格成立。
  - **合并联盟：** 矩阵博弈中，细分博弈（11 国 + 11 个 B_i）的核心在合并后仍是核心，x^m(S) ≤ c^m(S) 对 17 个联盟都由定理保证；物理联盟网络（拆开的 KVL 回路、整体移出的非成员组件）不是矩阵博弈，所以是经验检验。按上面的恒等式，合并余量 = W20 余量 − D_S，而 D_S 的大小没有先验：
    - 若燃料舱的多付额主要来自 SG 的航运甲醇（x_B 的 81.4 %），含 SG 的联盟 D_S 接近 D ≈ 3.8 bn，去 MM（W20 余量 2.85）、去 TH（2.80）、去 PH（3.19）会降到 0 附近或略负，去 BN / 去 TL（3.81）接近 0，**非 GMS（1.39）可能为 −2 bn 量级**；
    - 若联盟内自供燃料舱燃料的增量成本高于一体化对偶价（缺少伙伴的资源与封存），Δ_S 更大、D_S 更小甚至为负，合并余量反而大于 W20；
    - 不含 SG 的 GMS、BIMP、非 LTMS 与去 SG（x_B(S) 5.6–16.0 bn）的 D_S 小，余量接近 W20（3.51、2.44、6.12、4.88 bn 减去不超过约 0.7 bn）。
