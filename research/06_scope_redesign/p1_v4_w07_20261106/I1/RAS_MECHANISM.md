**RAS 解的结构（EXACT）：** 收敛后 tfa_cs / x⁰_cs = r_c · σ_s 对每个国家、每个部门严格成立（以 ID 为基准 r_ID = 1：σ = 工业 2.6186、交通 2.8536、居民 0.7260、商业 2.1101、农业及其他 3.2825；r_c：TH 0.772、VN 1.187、MY 0.526、PH 0.793，余类推，`/home/jin/v4i1/anchors_v3_ras.json`）。因此**每个国家每个部门的倍数 = 国家系数 × 部门系数**：m_ind,c = r_c × 2.6186（TH 2.022、VN 3.108、MY 1.378，与锚表一致）。

**第 66 项"倍数法"的实际形式：** "倍数法"即"2050 值 = 2019 基数 × 倍数"。D1 表（`d1_demand_2050.py:224-260`，决策 22、34、66 的 R1 比率法）里倍数 = g_c × k_s（g_c 为 AEO8 人均 × 人口增长相对东盟均值，k_s 使东盟 10 国部门合计等于"2019 基数 × 2019→2022 衔接 × AEO8 BAS 2022→2050 增长"）；现行主算的锚表（`m08b_demand.py`，决策 126 / 129 / 134 与 DFX F1）把倍数换成上表的 RAS 形式 m_cs = r_c σ_s，即"ATS 工业倍数"。两种形式都是"国家系数 × 部门系数"，都通过东盟部门合计把各国联系起来。

**国家锚是 AEO8 唯一的国别数字（VERIFIED）：** AEO8 附录 C.2 / C.3 只有东盟合计；C.8 给各国人均 TFEC，不分部门（`AEO8_2050_DEMAND.md`；全文检索无各国 × 部门历史或预测表）。模型里"ID 工业锚 2,027.97 TWh"不是 AEO8 印刷值，而是 RAS 由东盟各国种子推出的。

## 2. 跨国耦合

**是哪一个约束（EXACT，INFERENCE 解释）：** 列约束。某国某部门种子 x⁰_cs 增大 → 该列合计增大 → 为保持 Σ_c X_cs = B_s，列系数 σ_s 下降 → **所有国家**该部门倍数同时下降；再经行约束（各国总量 A_c 不变），各国其他部门的份额上升。例：只补 VN 非工业柴油（道路 58.9、农业 16.0、商业 4.2、铁路 0.6 TWh，2019）后，VN 交通种子 +60.2 TWh（道路 + 铁路；铁路父、子行在种子里各计一次，W12 F2），农业及其他 +16.0、商业 +4.2 → σ_交通 下降 → 其他国家交通锚下降、工业锚上升（ID 工业锚 +54.3 TWh），VN 自己的工业锚下降。

**是否设计意图：** DFX_RULES.md 第 1 节（`research/06_scope_redesign/p1_dfx_20261026/DFX_RULES.md:12-26`）只要求"国家锚不变"与"部门合计等于 C.3"同时满足，没有讨论单国种子修正的跨国传递（VERIFIED）。耦合是同时满足这两组 AEO8 约束的数学必然（INFERENCE：不是被讨论过的设计意图）。它在种子正确时无害；种子有国别误差时，会把一国的误差按其他国家在该列的份额分摊出去。

**W12 数字的口径更正（EXACT）：** W12 情形 B 用的是"汇总表全部 `pe_*` 列之和"（热分档列与生物质溢出前后两列重复计入）。按 `T_v2` 的定义（`v3_industry.CARRIERS` 12 列，生物质取溢出前）：VN −71.27、ID +41.97、TH +25.86、MY +13.54、PH +5.57 TWh；按 W12 口径复算为 VN −72.15、ID +42.25、TH +34.95、MY +13.54、PH +7.41（与 W12 所报 −71.2 / +41.7 / +34.5 / +13.3 / +7.3 相符）。TH、PH 的差别来自重复计入的热分档列。

## 4. 分类与口径建议（PROPOSED）

见 `CORRECTION_CLASSIFICATION.csv`（21 条）。原则：
1. **(i) 国家统计同样有的错误 → 口径 I（倍数不变）。** AEO8 的国家总量含同一错误，修正应同比例改锚。例：ID 自备煤（第 204 项已定）、TH / PH 糖厂蔗渣闭环（若 EPPO 也记在工业）。
2. **(ii) 只在我们提取或模型链中的错误、(iii) UNSD 独有的估计 → 口径 II（AEO8 国家总量不变）。** 锚的构造建议用 **IId**：各国总量取 AEO8、部门拆分随本国修正后的种子（沿用 v3 RAS 的部门系数），不把误差传给他国；代价是东盟部门合计偏离 C.3，须在 W08 报告偏离量（PROPOSED）。若坚持 C.3，用 IIa（现行 RAS）并接受跨国传递，或用 IIb（冻结锚，修正只改本国倍数）。三者的选择是用户决定（报告第 0.1 节第 3 问）。
3. **结构性修正**（钢、水泥、镍、纸浆造纸、乙烯、玻璃、氧化铝、混合拆分、甲醇份额）不改 2019 种子，两种口径结果相同。
