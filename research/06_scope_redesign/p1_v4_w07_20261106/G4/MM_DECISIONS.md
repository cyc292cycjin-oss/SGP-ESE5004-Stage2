# MM（缅甸）待决问题

数字出处：`MM_*.csv`、`evidence/`、`EVIDENCE.json`（键 `chain.*.MM.*`、`facts.*`）。2050 年量均为口径 I（ATS 工业倍数不变），"主算" = 第 207 项热值 + 自备 (b) 中心值 + 水泥 (ii) + 新增产品（闭环规则）：`T_v2` 60.74 TWh、"其他" 43.95 TWh（72.4 %），v3 为 61.03 / 45.12 TWh（73.9 %）。

1. **煤热值取 UNSD 23.26 还是实物证据？** UNSD SDMX 2019 对 MM 硬煤各流向统一用 23.26 GJ/t（VERIFIED）；USGS 2017–18 亚太卷表 3 把 2018 年缅甸煤产量记为褐煤 1,201 kt，ADB 2016 写"多为低质褐煤与次烟煤"——两条独立来源都只是煤种描述，没有实测热值。
   - **推荐：** 主算 23.26（第 207 项默认），IPCC 次烟煤 18.9 作敏感性（`T_v2` −0.36 TWh）。
   - **理由：** 第 207 项"用证据值"要求有可用的实物热值；这里能用的只有 IPCC 按煤种的缺省值，不是缅甸实测；MM 工业煤 2019 年只有 3.64 TWh，结论对两种取法都不敏感。若审阅端认为煤种分类即构成"两条实物证据"，改用 18.9 即可，数值已备。
2. **自备电厂 (b) 中心值取低档（66 kt，207 热值下 0.43 TWh）是否接受？** GIPT 2019 年自备煤电 190 MW：Tigyit 2 × 60 MW（标为钢铁）、Myainggalay 水泥 30 MW（2018 年投运）、Mawlamyine 水泥 40 MW（封存，日期不详）。
   - **推荐：** 接受低档为中心值；中、高档（212 / 271 kt）作敏感性（`T_v2` −0.89 / −1.19 TWh，对无自备处理）。
   - **理由：** v3 已记录 UNSD 非金属矿物行比按 EDGAR 熟料算的窑燃料少 1.42 TWh，自备煤若在该行内，缺口扩大到 1.90 / 2.94 / 3.37 TWh，档位越高越难成立；Mawlamyine 已封存；MM 自备转换项只有天然气。利用小时（UNSD MM 自备 3,876 h）与煤耗率（PLN 0.540–0.628 t/MWh × UNSD ID 24.48 GJ/t）出处见 `MM_CAPTIVE.csv`，后两者是印尼类比（C 级）。
3. **Tigyit 的煤不在工业行，是否需要处理？** UNSD 2019 年 1,382 kt 煤记在电厂转换（导出：主营；SDMX 新版：自备，E），推断即 Tigyit 用煤；但 120 MW 全年满发也只有 1.05 TWh，按 23.26 GJ/t 需要效率 ≤ 11.8 % 才烧得掉 1,382 kt。
   - **推荐：** 工业侧不改；把"MM 电厂转换用煤可能偏高"转给 W08 / 发电侧核对。
   - **理由：** 该量不在 `T_v2` 内；问题属于发电燃料的统计质量。
4. **"其他植物性材料与残渣"（5150）33,900 TJ（9.42 TWh）是否进入 `T_v2`？** UNSD 当前库（SDMX，A 级）报了 MM 工业 5150，模型所用的 UNdata 导出没有这一品种。
   - **推荐：** 主算留在 `T_v2` 之外（第 206 项第 3 条闭环规则：企业自产自用残渣及其热需求不进 `T_v2`；与导出缺失的现状一致）；"作为外购燃料加入"作敏感性（`T_v2` +8.57 TWh）。
   - **理由：** 量级与 MM 稻谷 26.7 Mt 的稻壳相容（推断为碾米厂等自用残渣，INFERENCE）；若审阅端判断其中有外售部分，应先取得 MM 国家能源平衡表再定。
5. **燃料木材工业行是否维持 UNSD 2019（7,250 千 m³，18.42 TWh）？** 该行 2005–2021 年每年都与"商业与公共服务"完全相等（17 年），2005–2017 年带"Estimate"，说明是固定分摊规则而非调查值；2022 年导出降到 1,131、SDMX 新版为 6,200。
   - **推荐：** 主算维持 2019 值（序列平稳、无 2018–2019 跳变）；SDMX 2022 水平作敏感性（`T_v2` −2.43 TWh）；向用户申请 MM 国家能源平衡表。
6. **蔗渣（1,145 kt，2.45 TWh）留在 `T_v2` 内还是按闭环规则移出？** 同时，SDMX 新版把 2019 年改为 850 kt（E）。
   - **推荐：** 主算保留（与 v3、S2 对 ID 蔗渣的处理一致，由整合会话跨国统一）；闭环移出（−2.24 TWh）与 850 kt（−0.58 TWh）作敏感性。
   - **理由：** 第 206 项第 3 条点名的是黑液、树皮、棕榈纤维与果壳；蔗渣是 UNSD 已报品种，按"已在 `T_v2` 内、按实际情况处理"保留，跨国口径由整合会话统一决定。
7. **新增显式产品是否接受？** 纸（FAOSTAT 2019 年 356 kt，A；基年 2023–2024，2050 年 256 kt）与非木浆（1 kt），精炼铜（USGS 亚太卷 2018 年 153 kt，2019 年按 R3 155 kt，2050 年 230 kt）。纸按闭环规则只计电与热（2050 年 0.15 TWh），PyPSA-Eur 结构中的生物质部分（0.55 TWh）单列、2019 年不从"其他"扣。
   - **推荐：** 接受；铜以 2018 年为基年（本机无更晚值），请补 USGS 缅甸国别卷 2019–2022。
   - **说明：** MM 的纸厂以回收纤维为主，生物质部分并非自产残渣；按规则它留在"其他"里随倍数增长，不会重复也不会遗漏，只是归属在"其他"而非纸。
8. **合成氨是否显式化？** USGS 亚太卷 2018 年缅甸合成氨含氮 53 kt（折 64 kt NH₃），GEM 3 家在运 369 kt；USGS 氮肥表 2019 年未列缅甸，v3 为 0。
   - **推荐：** 暂不加入主算（缺 2019 年及以后产量）；`MM_SUBSECTORS_V4.csv` 中列为不计入项（2050 年产品 0.50 TWh 氨）。
9. **水泥修正 (ii)（+0.11 TWh）是否采用？** EDGAR 2.A.1 ÷ 0.52 恰为 USGS 2019 水泥 × 0.786（MM、KH、LA 相同），EDGAR 熟料不是独立证据。
   - **推荐：** 采用 (ii)，与 ID 一致；补 UN Comtrade 熟料贸易后再核熟料比。
