# BN（文莱）待决问题

主算 2050 年 `T_v2` 1.63 TWh、"其他" 1.24 TWh（76.2 %）；v3 为 1.68 / 1.01 TWh（60.2 %）。占比上升来自水泥 (iii)：分母（`T_v2`）减小、2019 年水泥扣除回到"其他"。

1. **水泥改为"只粉磨" (iii)？** GEM：BN 只有 1 家粉磨站（0.5 Mt/a），没有熟料产能；USGS 2019 年 BN 水泥 100 kt（r, e），而 EDGAR 2.A.1 推得 2019 年熟料 228 kt，是水泥的 2.28 倍（EDGAR 用的是较早的水泥估计，INFERENCE），v3 据此在 2019 年扣了 0.30 TWh 窑燃料并在 2050 年按全流程水泥计 0.32 TWh。
   - **推荐：** 采用 (iii)：EDGAR 2.A.1 视为 0，2019 年只扣粉磨电（按 USGS 100 kt），2050 年只计 PyPSA-Eur 水泥比中的电（0.04 TWh）。`T_v2` −0.05 TWh、"其他" +0.23 TWh。修正 (ii)（保留窑燃料）作敏感性。
   - **理由：** 两条独立证据（GEM 厂型、EDGAR 与 USGS 的比值不可能）。
2. **化工设施（第 202 项第 4 条，不计入）：** GEM 在运产能按 0.85 利用率与 ETSAP BAT 能源单耗，恒逸 PMB（烯烃 1,500、芳烃 2,000 kt，2019 年投产）与文莱甲醇（850 kt，2010 年）合计 9.80 TWh，加文莱化肥（氨 803 kt，2021 年）为 11.94 TWh，是 BN 2019 年工业终端 2.21 TWh 的 4–5 倍。
   - **推荐：** 维持不计入，差异表见 `evidence/BN_CHEMICALS_DIFFERENCE_G4.csv` 与 `BN_SUBSECTORS_V4.csv`。
   - **说明（VERIFIED 行，INFERENCE 解释）：** 这些能耗在 UNSD 中不在工业终端：甲醇用气在非能源用途（BN NEU 天然气 2019 年 5.46 TWh，在 `T_v2` 外）；恒逸的煤在自备电厂转换（341 kt），2020 年起另有"炼厂自用"褐煤 525 kt（SDMX），其电记在化工行（507.7 GWh）。W08 需核对 NEU 气按 0.839 倍增长与恒逸二期（2028 年在建）是否一致。
3. **自备电厂：** 不等式成立；GIPT 2019 年 220 MW（恒逸 4 × 55 MW）的煤全部在 UNSD 自备转换项，BN 工业煤为 0，自备电已作为化工行用电记录——UNSD 已处于选项 (b) 的状态。**推荐：** 不处理（(b) 效果 0）。
4. **"其他"桶的构成：** 2019 年主要是工业 n.e.s. 柴油 115.3 kt（1.38 TWh），本机没有可拆分的数据。**推荐：** 维持，列入缺数（BN 能源平衡表）。
5. **煤热值：** BN 无工业用煤，第 207 项对 `T_v2` 无影响；SDMX 褐煤父品种 18.841 GJ/t 记录备 W08 发电侧使用。
