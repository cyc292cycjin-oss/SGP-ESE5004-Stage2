# ID 待决问题（W07 G0，印尼定稿）

每条给出推荐（PROPOSED）与理由；数字出处见 `REPORT.md` 对应节与 `EVIDENCE.json`。主线 = 热值 20.29 GJ/t、口径 I、按指令顺序全部施加。

## 1. NPI 用 Wei Case 4 还是 Case 3（影响最大）

- **现状：** 按指令"NPI 产量用 NPI 算例、镍铁用镍铁算例"，主线 NPI 用 Case 4-NPI（高炉，电 1.04、燃料 144.15 MWh/t Ni），2050 年镍 334.23 TWh，"其他"占比 **50.3 %**；Case 3 全部（v3/S2 口径）为 162.65 TWh、占比 **62.9 %**。`T_v2` 不变（守恒式），差别全在"其他"桶（−171.58 TWh）。
- **证据（报告第 3 节）：** (a) Wei 表 4 写明 Case 4 是高炉冶炼，Case 3 是 RKEF；本机 CREA/GEM 2025 写明印尼 NPI 产线为 RKEF，镍园区自备燃煤锅炉为 RKEF 供基荷电；(b) Case 4 推出 2019 年镍用电 2.69 TWh，只有 GIPT 镍自备煤电发电量（中档 10.47 TWh）的 0.26 倍，而 Case 3 为 1.08 倍；(c) Case 4 推出 2019 年焦炭 4,708 kt，是 UNSD 2019 印尼工业焦炭消费（578 kt）的 8.1 倍。
- **推荐：** NPI 主算改用 **Case 3（RKEF）**，Case 4 与 NIUPPER（占比 32.2 %）作上界敏感性。理由：三条独立证据都与高炉路线不符，Case 3 的工艺与印尼实际一致且与 2019 年自备发电量吻合。若需要更贴近 11–14 % 含镍 NPI 的 RKEF 单耗，需用户提供文献（`ID_MISSING_DATA.csv` 第 2 项）。
- **需要决定：** 采用 Case 3（推荐）、Case 4（指令字面）还是其他文献值。

## 3. 蔗渣是否按闭环规则处理

- UNSD ID 报了蔗渣（5120，6,964.7 千 t，14.93 TWh），目前在 `T_v2` 内；生物质潜力中的甘蔗残渣按同一国家母线供给（加工残渣份额 0.706，2050 年约 22.43 TWh）。
- **推荐：** **维持在 `T_v2` 内**。理由：第 206 项第 3 条要求"若 UNSD 报了，这些残渣已在 `T_v2` 内，按实际情况处理"；需求与供给目前在同一母线上自洽（`d1_biomass.py` 第 321 行的自用说明）。若改为闭环（敏感性：`T_v2` −35.24 TWh，占比 49.0 %），须同时从潜力中扣除蔗渣部分，否则重复。

## 4. 生物质潜力中的厂内自用残渣（W08）

- `BIOMASS_POTENTIAL_2050.csv` 中 ID 棕榈纤维 148.55、果壳 66.02 TWh（2050，主值），压榨厂今天把纤维全部、果壳一部分烧在厂内锅炉。闭环规则把这部分热需求留在 `T_v2` 外，而潜力仍把这些残渣作为可供其他需求的燃料：**重复约 148.6 TWh（纤维）+ 果壳厂内部分（0–66.0 TWh）**，占 ID 固体生物质潜力 976.75 TWh 的 15–22 %。黑液、树皮在需求与潜力两侧都没有，口径一致。
- **推荐：** W08 从潜力中扣除纤维的全部与果壳的厂内部分（果壳出口资料见 `ID_MISSING_DATA.csv` 第 4 项）；二者择一，不要既扣潜力又把厂内热需求加回 `T_v2`。

## 7. 纸浆造纸的外购燃料

- 闭环规则下，2019 年从"其他"扣的只有电 15.91 TWh 与非生物质热 0.66 TWh（PyPSA-Eur 结构，按"其他"桶煤油气结构摊：煤 0.31、油 0.18、气 0.17）；2050 年显式只计电 33.39 与低温热 1.38 TWh，生物质 95.42 TWh 单列。
- 对照：HEESI 2019 造纸售煤 3,305 kt，其中按 S1 中心值（造纸取低档）3,104 kt 进自备电厂（含 UNSD 已记在转换项的 162 kt；其余已由 (b) 换成电），余约 201 kt（20.29 GJ/t 下约 1.13 TWh）可能是锅炉用煤，比 0.66 TWh 多约 0.5 TWh（2050 年约 1 TWh 量级）。
- **推荐：** 接受 PyPSA-Eur 结构（差额小）；若用户希望按 HEESI 余量计，可在 W08 改为 1.13 TWh。
