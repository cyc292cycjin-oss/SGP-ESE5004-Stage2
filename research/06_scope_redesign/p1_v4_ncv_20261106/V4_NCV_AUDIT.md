## 0. 结论摘要

1. **v3 的折算系数（VERIFIED）：** 需求基数只有一条折算链：UNSD 2019 原始记录 × 冻结的上游字典（`pypsa-asean` `get_conv_factors`，`FROZEN_UPSTREAM_CONVERSIONS.json`）→ `BASE_RECONSTRUCTION.json` → D1 表 → ATS 锚表 → `s3_0_industry.py` 的 `T_v2`。字典每个品种只有一个数，不分国家、不分年份；数值就是 UNSD 标准低位热值（硬煤 25.8、褐煤 14.0 GJ/t，油品与 IPCC 缺省值相差不超过 0.07 %）。天然气按 UNSD 规则把高位 TJ 乘 0.90（`reconstruct_base_accounts.py:79`）。`industry_cache.json` 只在 `s3_0_industry.py:158` 提供载体内分行业占比，不提供总量。
2. **UNSD 自己用国别值（VERIFIED，B）：** 把 UN《2019 能源平衡》的 TJ 与模型所用 UNdata 导出的实物量相除，在至少两个实物量不同的流向一致到 0.5 % 以内时，得到 UNSD 2019 年实际使用的煤热值：**ID 硬煤 24.480（v3 −5.1 %）、VN 23.446（−9.1 %）、MM 23.260（−9.9 %）、PH 褐煤 22.064（+57.6 %）、KH 褐煤 19.878（+42.0 %）、SG 25.800（不变）GJ/t**。MY、TH 的出版物与导出数据版本不一致，推不出；LA 由仓库中较新版本的平衡导出联立得褐煤 9.63、无烟煤 25.12 GJ/t（残差 ≤ 0.02 %）。油品与天然气在数据版本一致的国家，平衡 TJ 恰等于"实物量 × UNSD 标准值"（比值 1.000），说明 UNSD 对油品用标准值、天然气乘 0.90，**v3 在油、气上与 UNSD 做法一致，不需修正**。

### 4.2 推荐（PROPOSED）

1. **首选 (b) UNSD 国别值**，统一用于 ID、VN、MM、PH、KH（SG 不变）：与活动量同源（同一套 UNSD 统计、同一数据版本），各国用同一方法得到，国家间可比性不受破坏；ID 值与 HEESI 2019 只差 0.8 %，说明 UNSD 采用了接近国家手册的值。只改 ID 或只改部分国家会破坏可比性，不建议。
2. **MY、TH、LA 维持 v3**，直到取得 UNSD SDMX 的 `CONVERSION_FACTOR`；推断值（MY 28.54、TH 褐煤 12.21 / 硬煤 26.4、LA 9.63 / 25.12）与国家手册值作敏感性。TH 是方案间分歧最大的国家（−1.75 % 至 +11.88 %），需 DEDE 按煤种的进口煤热值。
3. **(c)、(d) 作敏感性。** ID 的 (d)（约 19–20 GJ/t）有实物证据支持（第 2.4 节），是最重要的下界：口径 I 下 ID `T_v2` −9.84 %、10 国 −3.46 %。若用户认为实物证据优先于"同源"，主算可改用约 20 GJ/t，但须对其他国家采用同一原则（按煤种的实测或手册值），否则失去可比性。
4. **增长口径**随第 204 项第 1 条用口径 I；口径 II 作对照并在报告中并列。理由：AEO8 锚本身来自各国国家统计（含其热值），口径 II 下热值偏差大部分被锚抵消；口径 I 下热值修正完整传到 2050。两者之间的选择是锚的解释问题，由用户决定。
5. **实施顺序（W08）：** 在 UNSD 行层面（`BASE_RECONSTRUCTION` 逐行）先改热值，再用同一热值把 S1 / S2 按实物量推出的扣减（自备用煤吨数、燃料木材体积等）折成能量；不要在能量层面把两项结果相加。

### 4.3 与 S1 / S2 的衔接

- **自备用煤 (b)：** S1 的 C = 装机 × 利用小时 × t/MWh（HEESI PLN 煤耗率，按吨）× 模型系数 7.167 MWh/t（25.8 GJ/t）。热值修正后 C 须用同一热值：中心值 72.01 (b) / 72.55 (c) / 55.59 TWh (d)；E（发电量）不变，隐含效率 E/C 由 0.253 升到 0.267 / 0.265 / 0.346。C 占"未细分工业"煤行的份额（28.2 %）不变。合并量化（ID，口径 I，`NCV_S1_COMBINED.csv`）：

交互项为正：热值下调已经作用在自备煤那部分上，两项单独相加会重复计算这一部分。S1 的 PLN 煤耗率与 HEESI 售煤都是按吨的统计，与 UNSD 实物量同口径；所以 S1 的结论（自备煤占煤行 22–58 %）不受热值影响，受影响的只是能量值。
- **燃料木材（S2 第 3 节）：** v3 9.144 GJ/m³ 与 UNSD 9.135–9.14 一致；国家值 TH 9.594、MY 9.7 GJ/m³（+5–6 %）；ID 只有按质量的 HEESI 13.50 GJ/t 与 APEC 14.06 MJ/kg，需密度才能换成体积。热值不确定性约 ±5–7 %，远小于 S2 面对的体积冲突（UNSD 工业一行 6,525 万 m³ 对 FAOSTAT 全国 4,041 万 m³、HEESI 0.9 TWh），所以燃料木材应先由 S2 定体积，再用统一的每立方米热值；若 S2 改按吨（FAOSTAT 或其他来源），须同时给出含水基准对应的热值。
- **甘蔗渣（S2 第 2.3 条）：** UNSD 6,964.7 kt 是含水约 50 % 的湿重，对应 7.72 GJ/t；S2 用甘蔗产量 × 蔗渣产率核对时，产率须为湿重口径。供给侧 `d1_biomass.py` 的 15 GJ/t 与此不一致，W08 应统一。
- **S2 维持 v3 热值（第 204 项第 3 条）：** S2 的合并量化都在 v3 热值下；W08 汇总时，本报告的热值修正按上面的顺序叠加，不能把 S2 与本报告的 TWh 直接相加（交互见上表）。
